# Геоаналитика событий социальной сети на PySpark

Учебный проект обработки Parquet-событий и справочника городов. В репозитории представлены три скрипта подготовки аналитических витрин.

## Задача

Связать географические координаты событий с городами, построить аналитику активности и выделить пары пользователей для рекомендаций знакомств.

## Реализация в src/scripts

| Скрипт | Результат |
|---|---|
| [users_mart.py](src/scripts/users_mart.py) | Актуальный и домашний город, локальное время, сведения о перемещениях |
| [zones_mart.py](src/scripts/zones_mart.py) | Недельные и месячные агрегаты событий и регистраций по зонам |
| [friends_mart.py](src/scripts/friends_mart.py) | Пары с общей подпиской в одной зоне, расстоянием до 1 км и без найденной переписки |

Расстояние вычисляется по формуле гаверсинуса. Используются Spark DataFrame API, оконные функции, join, pivot, агрегации и `left_anti`.

## Входные и выходные данные

Вход: Parquet-события `/user/master/data/geo/events` и CSV-справочник `/user/marbiana/data/geo.csv`.
Выход: Parquet-витрины в `/user/marbiana/data/`.

Требуются PySpark, Java, findspark, доступ к исходным данным и согласованное Hadoop/Spark-окружение. Пути и параметры в текущей версии зафиксированы в коде.

## Версии файлов

В корне есть альтернативные версии трёх скриптов. Они отличаются от `src/scripts/` и сохранены до проверки на контрольных данных.
Описание выше относится к `src/scripts/`; ни один вариант не объявлен проверенным финальным решением.

## Ограничения перед демонстрацией

- Домашний город определяется количеством дней с событиями, а не доказанным непрерывным проживанием.
- В users_mart часовой пояс зафиксирован как Australia/Sydney.
- Неделя и месяц в zones_mart группируются без года; многолетний набор требует корректировки.
- Для событий без message_id нужно проверить ключ оконной группировки.
- Cross join событий со всеми городами требует оценки на большом объёме.
- Пары рекомендаций могут повторяться при нескольких общих подписках.
- Синтетические данные и автономный demo пока не добавлены.
